# PR Summary Prompt

Write a concise pull request summary from local changes.

## Instructions

1. Inspect branch, base branch when available, changed files, and git diff.
2. Read nearby code and docs only as needed to understand impact.
3. Summarize what changed, why, and how it was verified.
4. Do not push, publish, create PRs, or change repo settings unless explicitly asked.

## Output

```markdown
## Summary

- ...

## Testing

- ...

## Notes For Reviewers

- ...
```
