## Flutter Review

When asked to review Flutter/Dart code: check `const` constructors used where possible, `setState` on smallest widget, `ListView`/`GridView` uses `.builder`, no heavy computation in `build()`, `dispose()` called for AnimationController/TextEditingController/FocusNode/streams, no `setState` after `dispose`, heavy work offloaded to `Isolate`/`compute`, `FutureBuilder`/`StreamBuilder` handle waiting/error/data states, platform channel names namespaced, data types serialisable. Security: no hardcoded secrets (use `--dart-define`), sensitive data in `flutter_secure_storage` not plain SharedPreferences, no debug flags in release. Release: version/build number updated, `flutter analyze` clean, obfuscation enabled. Order findings P0–P3 with lib/path/file.dart:line references.
