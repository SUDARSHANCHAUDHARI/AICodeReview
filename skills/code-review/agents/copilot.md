## Code Review

When asked to review code changes: inspect git status, branch, changed files, and diffs. Read `PROJECT_CONTEXT.md` when present. Focus on correctness, security, performance, and missing tests — not style. Order findings by severity (P0–P3) with `file:line` references. Do not edit files or push unless explicitly asked.

Severity guide: P0 = must fix before merge, P1 = should fix, P2 = useful, P3 = optional polish.
