# Codex PR Summary

## Workflow

1. Inspect branch, base branch when available, changed files, and git diff.
2. Read nearby code and docs only as needed to understand user-facing impact.
3. Summarize what changed, why it changed, and how it was verified.
4. Do not push, publish, create PRs, or change repo settings unless explicitly asked.

## Output

```markdown
## Summary

- ...

## Testing

- ...

## Notes For Reviewers

- ...
```

Keep it concise and concrete. Avoid marketing language.
