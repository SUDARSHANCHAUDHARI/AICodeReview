# Codebase Explainer

When asked to explain a codebase, follow this workflow:

1. Identify stack files: `package.json`, `build.gradle.kts`, `go.mod`, `Cargo.toml`, etc.
2. Read README, `PROJECT_CONTEXT.md`, `AGENTS.md`, entry points, representative files, and tests.
3. Build understanding from actual files — do not guess.
4. Explain architecture, key modules, data flow, conventions, testing, and risk areas.
5. If asked to fill `PROJECT_CONTEXT.md`, use only verified facts.

Name actual files and commands in your explanation.
