## Agent Config Review

When asked to review AI agent config files: read CLAUDE.md, AGENTS.md, .cursor/rules/, .github/copilot-instructions.md, GEMINI.md, CONVENTIONS.md, and PROJECT_CONTEXT.md. Check for hardcoded secrets or tokens (P0), empty placeholder fields like `- Build:` with no value or TODO/TBD left in (P1), vague non-actionable instructions (P2), and cross-agent inconsistencies (P2). Verify SKILL.md and .mdc files have valid YAML frontmatter. Do not edit files unless explicitly asked.
